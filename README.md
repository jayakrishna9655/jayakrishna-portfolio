## 🛠️ How to Deploy to GitHub Pages (`jayakrishna-portfolio`)

1. **Create Repository:**
   - Create a new public repository on GitHub named: `jayakrishna-portfolio`

2. **Push Code:**
   ```bash
   cd "c:\Credo System\Microservice\portfolio"
   git init
   git add .
   git commit -m "Initial commit: Jayakrishna portfolio"
   git branch -M main
   git remote add origin https://github.com/jayakrishna9655/jayakrishna-portfolio.git
   git push -u origin main
   ```

3. **Enable GitHub Pages:**
   - Go to **Settings** -> **Pages** in the `jayakrishna-portfolio` repo.
   - Set **Source** to `Deploy from a branch`.
   - Branch: `main`, Folder: `/(root)`.
   - Click **Save**.

4. **Live URL:**
   - **`https://jayakrishna9655.github.io/jayakrishna-portfolio/`**
