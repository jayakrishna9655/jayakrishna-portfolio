      Reactive Gateway & Reverse Proxy

      Provides a unified entry point for all client requests. Evaluates routes via Java DSL, strips path prefixes, and transparently load-balances downstream requests using Eureka service records.

      • ✔ Java DSL RouteLocatorBuilder routing
      • ✔ Direct & prefixed route matching with stripPrefix(1)
      • ✔ Client-side load balancing via lb:// protocol

      • ✔ Netflix Eureka Server implementation
      • ✔ Health monitoring via 30s heartbeat checks
      • ✔ Dynamic scale-up/down instance discovery
